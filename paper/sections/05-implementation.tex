\section{Implementation Status}

The public repository uses a flattened, project-owned history.  The imported
engine is isolated under \path{reference/}; its pinned revisions and license
boundary are explicit.  Changes made for \project{} remain ordinary reviewable
commits on top of that snapshot.

As of 9 August 2026, the following components are implemented:

\begin{itemize}
  \item a standalone Python replay inspector and a stricter owning C++ loader;
  \item direct headless compatibility playback from the first populated stage;
  \item bounded, complete-mask input injection through the original callback;
  \item deterministic JSON diagnostics and explicit terminal reasons;
  \item a retail-data manifest and local SHA-256 verifier;
  \item experimental canonical projection revision 0.2 with explicit endian
  and raw-float encoding, stable slot identities, relative script offsets,
  domain-separated subsystem and frame hashes, and real runtime serializers
  for eleven gameplay subsystems;
  \item future-live ANM serialization for Player, bullets, enemies, lasers,
  items, Stage, GUI/message, and effects, plus an independent Python validator,
  first-mismatch comparator, corruption tests, and payload statistics;
  \item a pinned Lean 4.32.0 Effect-reuse model with a checked active-only
  noninterference counterexample and a commuting allocation theorem for a
  narrow dormant radius/angle shadow, with no admitted theorem or custom axiom;
  \item a hash-bound x87/XMM audit that attributes instruction sites and direct
  helper calls through the authoritative mapping, emits a path-free JSON
  summary, extracts all 244 mapped comparison/status/branch chains and bounded
  helper-result consumers, and has proprietary-input-free synthetic tests;
  \item checked Lean decodes of target control word \code{0x027f} and the D3DX
  toward-zero profile \code{0x0e7f}; their narrow theorems cover precision,
  rounding, exception-mask fields, and corresponding SoftFloat configuration
  values, but neither arithmetic operations nor loader-established entry state;
  \item a reproducible, commit-pinned SoftFloat Release 3e differential probe
  for results and six x87 exception bits across five basic operations, two
  store widths, \code{frndint}, and two signed \code{fistp} widths, using
  finite binary32-derived operands and canonical 53-bit-precision extended
  intermediates; the same probe checks DWORD/QWORD \code{fcomp} C0--C3 and
  fixed infinity/NaN/denormal priority cases;
  \item a finite-input Lean exception-priority model checking the rejected
  denormal rule's divide-by-zero and negative-square-root counterexamples and
  the tested \code{frndint}/\code{fstp}/\code{fistp} boundary distinction;
  \item a local-only extractor and freestanding i386 harness for the verified
  117-byte \code{\_\_ftol2} body, an independent exact-dyadic truncation model,
  and Lean checks of the helper correction table, EDX:EAX reconstruction, and
  low-32-bit projection;
  \item a canonical, hash-bound arithmetic-obligation ledger containing 244
  comparison and 77 helper-call addresses, conservative per-site status,
  generator/audit hashes, and a proprietary-input-free structural test;
  \item a source/sink candidate ledger covering all 77 helper calls at a pinned
  authoritative source revision, with 68 omission-after-noninterference and
  nine retain candidates, all explicitly unproved;
  \item a byte-free static audit of 17 critical ECL dispatch instructions and
  its 25-entry jump table, plus Lean checks that the decoded 32-bit classifier
  recognizes exactly IDs $-10025$ through $-10001$ and that all other integers
  induce the same literal-resolution path;
  \item a byte-free audit of all 37 instructions in the 117-byte helper,
  recording the masked-invalid integer-indefinite path and its zero low-EAX
  observation, plus the corresponding Lean bit-vector projection theorem;
  \item a fixed-data ECL writer audit over 321 subroutines and 8,384
  instructions, checking 1,844 output operands and all 80 unchecked increment/
  decrement destinations, plus 28 retail instruction signatures, 17 source
  anchors, and a Lean writer-policy reduction;
  \item a byte-free player-position audit of 95 instruction signatures across
  eight mapped functions, 21 pinned source anchors, five binary32 constants,
  four character-speed records, and four comparison contracts, plus total Lean
  proofs of non-NaN clamping, initial/respawn bounds, and grab-box bounds;
  \item a byte-free audit of 77 point-item score instructions, four score
  profiles, five difficulty-table entries, and eight helper calls, together
  with Lean proofs over exact rational and exceptional coordinate classes of
  collection bounds, total score bounds, and signed-i32 safety;
  \item a GDB-based debug-runner probe and sealed report covering 2,081
  collected point items in four Linux replay runs, with source, runner, replay,
  probe, and data-manifest identities recorded;
  \item Linux CI that builds the reference runner and cross-checks both replay
  validators on three valid and three deliberately malformed cases, while also
  requiring canonical-record corruption to fail closed.
\end{itemize}

The current compatibility path intentionally restores each replay stage
snapshot because that mirrors shipped playback and enables oracle development.
It is not yet canonical proof playback.  No zkVM guest is frozen or claimed to
be implemented.  Projection revision 0.2 commits only to selected fields.  A
field-level mismatch snapshot remains open, and the state audit has already
identified inactive Effect residue and dynamic screen-effect jobs that prevent
claiming projection closure.
